## ✨ Key Features

- 🛸 **Cyber Hologram Hero**: Dynamic typewriter role cycling, breathing neon aura, laser scanline animation, HUD corner brackets, and orbiting tech badges.
- ⚡ **Interactive Particle Constellation**: Real-time canvas physics with mouse proximity repulsion.
- 🎵 **Native Web Audio FX Synthesizer**: Pure procedural UI soundscapes (hover, click, success) with zero external audio assets.
- 💻 **Interactive Cyber Terminal**: Built-in CLI in the About section accepting commands (`skills`, `projects`, `contact`, `clear`) with quick command chips.
- 🍱 **Modern Bento Grid Layout**: Organized story highlights, credential metrics, and experience milestones.
- 🔍 **Interactive Project Showcase**: Filterable project gallery with cursor spotlight tracking and rich case study modals.
- 📬 **Interactive Glass Contact Form**: 1-click clipboard copy, WhatsApp direct chat, and confetti burst celebrations on submit.
- 🕒 **Live PKT Clock Widget**: Dynamic real-time Asia/Karachi time tracking in the footer.
- 📱 **Fully Responsive Design**: Optimized for all viewports with seamless touch detection and custom cursor controls.

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/maaz-ahmad06/MyPortfolio.git
   cd MyPortfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
